# Security reporting

Security fixes target the latest published release.

Never post passwords, DNI/NIE account identifiers, contract identifiers, CAPTCHA
keys, JWTs, HA storage exports or private consumption traces in public issues.

Use **Security → Report a vulnerability** when available. If private reporting
is unavailable, open an issue asking for a private reporting channel without
including the vulnerability details or secrets.

Integration diagnostics contain allowlisted settings, counts and status.
Additional logs and screenshots still need review before sharing.
